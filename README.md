# 📌 About The Project

Cricket is more than just a game in India — it's an emotion.  
This project is an interactive **IPL Analytics Dashboard** built using **Power BI**, designed to explore team performance, player statistics, match trends, venue insights, and season-wise analysis from IPL 2008 to 2024.

The dashboard transforms raw cricket datasets into meaningful visual stories, helping users easily analyze:
- Team dominance across seasons
- Match-winning patterns
- Player performances
- Toss impact on results
- Venue trends
- Overall tournament statistics

The project focuses on combining **data analysis**, **visual storytelling**, and **interactive dashboard design** to create an engaging analytics experience.
